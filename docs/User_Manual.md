# User Manual

# AI-Powered Building Quantity Estimator & BOQ Generator

## Version

1.0

---

# 1. Introduction

Welcome to the **AI-Powered Building Quantity Estimator & BOQ Generator**.

This application helps civil engineers, contractors, architects, quantity surveyors, and students estimate construction material quantities and automatically generate a Bill of Quantities (BOQ).

---

# 2. System Requirements

### Hardware

* Laptop/Desktop
* Minimum 4 GB RAM
* Internet Connection

### Software

* Google Chrome
* Microsoft Edge
* Mozilla Firefox

---

# 3. Login

1. Open the application.
2. Register a new account or log in.
3. After login, the Dashboard will appear.

---

# 4. Create a New Project

Click **New Project**.

Enter:

* Project Name
* Building Type
* Number of Floors
* Length
* Width
* Height

Click **Save**.

---

# 5. Estimate Materials

Click **Estimate**.

The system calculates:

* Cement
* Steel
* Bricks
* Sand
* Aggregate
* Concrete

---

# 6. Generate BOQ

Click **Generate BOQ**.

The application automatically prepares a Bill of Quantities containing:

* Material Name
* Quantity
* Unit
* Unit Cost
* Total Cost

---

# 7. View Cost Estimate

The dashboard displays:

* Total Material Cost
* Quantity Summary
* BOQ Table

---

# 8. Download Reports

Users can download:

* PDF Report
* Excel Report

---

# 9. Manage Projects

Users can:

* View previous projects
* Edit project details
* Delete projects
* Create new projects

---

# 10. Error Messages

Examples:

* Invalid building dimensions
* Missing required fields
* Internet connection issue
* Report generation failed

The application displays clear messages to help users correct the problem.

---

# 11. Tips

* Double-check building dimensions before estimating.
* Review the generated BOQ before using it for construction.
* Keep material rates updated for more accurate cost estimation.

---

# 12. Support

For technical issues or suggestions, contact the development team through the project's GitHub repository.

# Conclusion

The AI-Powered Building Quantity Estimator & BOQ Generator is designed to simplify quantity estimation and BOQ preparation, helping users save time, reduce manual calculations, and improve estimation accuracy.
