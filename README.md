# 🏗️ AI-Powered Building Quantity Estimator & BOQ Generator

## 📌 Overview
An AI-powered web application that automatically estimates construction material quantities and generates a Bill of Quantities (BOQ) from building plans.

## ✨ Features
- Upload building plans
- AI-assisted quantity estimation
- Automatic BOQ generation
- Material cost estimation
- Download reports (PDF/Excel)

## 🛠️ Technology Stack
- Frontend: HTML, CSS, JavaScript
- Backend: Python (Flask)
- AI: OpenAI API / Gemini API
- Database: SQLite
