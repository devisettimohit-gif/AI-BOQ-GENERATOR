# AI-Powered Building Quantity Estimator & BOQ Generator

## Project Overview
This project is an AI-powered web application that helps civil engineers estimate construction material quantities and automatically generate a Bill of Quantities (BOQ) from building plans.

## Features
- Upload building plans
- AI-assisted quantity estimation
- Automatic BOQ generation
- Material cost estimation
- Export reports (PDF/Excel)
